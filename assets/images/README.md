# Images

* `logo_mark.png` — the app mark (pastel water droplet). Also used to generate
  the Android launcher icons in `android/app/src/main/res/mipmap-*/`.

The UI deliberately avoids photographic assets: everything else (cards, glow,
blobs, gradients, the droplet, the breathing circle) is drawn with Flutter
painters so the design stays crisp at any density and the app stays small.
